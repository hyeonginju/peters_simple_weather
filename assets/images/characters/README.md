# 옷차림 캐릭터 일러스트

이 폴더에 아래 파일명으로 PNG를 넣으면, 앱이 자동으로 강아지 플레이스홀더 대신
실제 이미지를 사용합니다. 코드 수정은 필요 없습니다.

| 파일명                         | 온도 구간 | 옷차림 키워드 |
| ------------------------------ | --------- | ------------- |
| `sleeveless_cool.png`          | 28° 이상  | 민소매·반바지 |
| `short_sleeve.png`             | 23~27°    | 반팔·얇은 셔츠 |
| `long_sleeve_cardigan.png`     | 20~22°    | 긴팔·가디건   |
| `hoodie_sweat.png`             | 17~19°    | 니트·맨투맨   |
| `light_jacket.png`             | 12~16°    | 자켓·가벼운 외투 |
| `trench_coat.png`              | 9~11°     | 트렌치코트·야상 |
| `wool_coat.png`                | 5~8°      | 울 코트       |
| `heavy_padding.png`            | 4° 이하   | 패딩·목도리   |

권장: 정사각형에 가까운 비율(예: 256×248), 배경 투명 PNG.
